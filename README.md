# Задание 1. Заполнение двумерных массивов (Вариант 1.4)

### Текст задачи
Первый массив, размерностью n x m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по строкам от первых элементов строки к последним. 
Второй массив, размерностью n x n, заполняется так: элементы, лежащие выше побочной диагонали, являются случайными числами из интервала [-65; 120], а лежащие на побочной диагонали и ниже, являются случайными числами из интервала [-3.5; 10.75]. 
Третий массив, размерностью n x n, заполняется для произвольного n так же, как для n=5. Матрица-образец из задания (для n=5) имеет вид:
11 10  4  3  1
 0 12  9  5  2
 0  0 13  8  6
 0  0  0 14  7
 0  0  0  0 15

### Алгоритм решения
1. Создан класс `Matrix`, внутри которого хранится двумерный массив.
2. **Первый массив** заполняется через цикл: программа просит пользователя ввести числа построчно.
3. **Второй массив** заполняется случайными числами. Программа проверяет позицию элемента: если он выше побочной диагонали, берется число от -65 до 120, иначе — от -3.5 до 10.75.
4. **Третий массив** строится по узору: сначала заполняется главная диагональ (11, 12, 13...), а затем верхняя часть матрицы заполняется по диагоналям в шахматном порядке (сверху вниз и снизу вверх).

# Задание 2. Работа с двумерными массивами (Вариант 2.4)

### Текст задачи
В городе П. есть N банков. Известны величины задолженностей банков друг другу. Укажите банк с максимальным долгом.

### Алгоритм решения
1. Создан метод `FindMaxDebtBank()`.
2. Программа проходит по каждой строке матрицы (каждая строка — это долги одного банка) и считает их общую сумму.
3. Находится строка с самой большой суммой, и возвращается её номер (индекс).

# Задание 3. Работа с двумерными массивами как с матрицами (Вариант 3.4)

### Текст задачи
Вычислить матричное выражение: 2*A - B^T * C. 
Необходимо реализовать перегрузку необходимых операторов и посчитать значение матричного выражения (решение без перегрузки не принимается). Перегрузить метод ToString() — сформировать строку из двумерного массива для отображения его на экране в виде таблицы.

### Алгоритм решения
1. Для красивого вывода матрицы в виде таблицы переопределен метод `ToString()`.
2. Написан метод `Transpose()` для получения транспонированной матрицы (B^T).
3. Перегружены операторы: `*` (умножение матриц и умножение на число) и `-` (вычитание матриц). Благодаря этому выражение в коде выглядит как `2 * A - B.Transpose() * C`.

# Задание 5. Бинарные файлы (Вариант 5.4)

### Текст задачи
Информация о багаже пассажира описывается массивом, где каждый элемент содержит название единицы багажа (чемодан, сумка, коробка и т.д.) и ее массу. Дан файл, содержащий сведения о багаже нескольких пассажиров. На сколько багаж максимальной массы отличается от багажа минимальной массы?

3. Метод `SolveTask5` загружает данные из файла, считает общий вес багажа каждого пассажира и находит разницу между самым тяжелым и самым легким багажом.
