# Задание 1. Заполнение двумерных массивов (Вариант 1.4)

### Текст задачи
Первый массив, размерностью n x m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по строкам от первых элементов строки к последним. 
Второй массив, размерностью n x n, заполняется так: элементы, лежащие выше побочной диагонали, являются случайными числами из интервала [-65; 120], а лежащие на побочной диагонали и ниже, являются случайными числами из интервала [-3.5; 10.75]. 
Третий массив, размерностью n x n, заполняется для произвольного n так же, как для n=5 (матрица имеет специальный узор, где главная диагональ заполнена числами 11, 12, 13, 14, 15, а остальные элементы выше нее заполняются по диагоналям в порядке, зависящем от четности).

### Алгоритм решения
1. Создан класс `Matrix` с единственным полем `_data` (двумерный массив типа `double`).
2. Для заполнения первого массива используется конструктор `Matrix(int n, int m)`, который в двойном цикле запрашивает значения с клавиатуры (заполнение идет по строкам).
3. Второй массив создается конструктором `Matrix(int n, bool isRandom)`. С помощью класса `Random` генерируются числа. Условие `i + j < n - 1` определяет, находится ли элемент выше побочной диагонали (тогда генерируется число от -65 до 120), иначе генерируется число от -3.5 до 10.75.
4. Третий массив создается конструктором `Matrix(int n, char pattern)`. Сначала заполняется главная диагональ, затем в цикле заполняются верхние диагонали в зависимости от их четности.
